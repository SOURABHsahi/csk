Executive Summary & Vision

Knome is an enterprise Knowledge Management and Social Collaboration platform engineered for MPOnline Limited. It unifies professional networking, blogging, and video/audio broadcasting.

💼 LinkedIn Hybrid

Networking feed, employee profiles, @mentions, reactions, and internal job board.

✍️ Medium Hybrid

Rich-text technical blogs, ArticleVersions snapshots, and tag discovery.

📺 YouTube & Spotify

Enterprise video channel and global persistent audio podcast player.

Full-Stack System Architecture

Built on modern enterprise standards with ASP.NET Core 10 backend and React 18 single-page application.

[React 18 SPA (Vite 5 / TailwindCSS)]
              │  HTTP REST / JSON
              ▼
[ASP.NET Core 10 Web API]
  ├── Middleware Pipeline (JWT Auth / Security Headers / Exception Handling)
  ├── 16 REST API Controllers ──► 14 Business Logic Services
  └── Entity Framework Core 10 (Database-First) ──► SQL Server DB
Slide 03 / 12

Backend Clean Architecture

Strict decoupling between API transport, business rules, repositories, and scaffolded data models.

  • Thin Controllers: Endpoints handle HTTP routing and delegate execution directly to business services.
  • Database-First Integrity: 100% scaffolded EF Core entity models (`Models/`) from SQL Server.
  • Unified Response Envelope: Standardized ApiResponse<T> returned across all 16 controllers.
Slide 04 / 12

Security & Role-Based Access (RBAC)

Stateless JWT authentication paired with 4-tier Role-Based Access Control and Indian DPDP Act compliance.

🔐 Security Baseline

BCrypt password hashing (work factor 11), Serilog PII scrubbing enricher, and Security Headers middleware.

👥 4 Role Tiers

Employee, Community Admin, HR Administrator, and System Administrator.

Slide 05 / 12

Core Content Creation Engines

Multi-channel publishing engine supporting posts, rich text blogs, video streaming, and podcasts.

  • Quick-Share Posts: Max 400 chars, media attachments, and automatic `@mentions` user mapping.
  • Article Engine: Automatic ArticleVersions audit snapshot created whenever article HTML is edited.
  • Media Channels: Video stream uploads (≤ 500 MB) and Podcast series channels (≤ 100 MB).
Slide 06 / 12

Polymorphic Interactions & Moderation

Unified interaction engine powering comments, reactions, bookmarks, and screening across all content types.

💬 Polymorphic Interactions

Comments, Reactions (Like, Love, Insightful, Celebrate), Bookmarks, and Shares shared across items.

🛡️ Real-Time Screening

Automatic content evaluation against BlockedUrls and RestrictedKeywords database tables.

Slide 07 / 12

Community Hubs & Member Governance

Public and private workspaces with administrative pinning limits and governance safeguards.

  • Join Request Workflows: Public channels auto-join; private groups require Community Admin approval.
  • Pinned Posts Limit: Maximum of 3 pinned posts safeguard per community workspace.
  • Sole Admin Safeguard: Prevents last remaining admin from leaving without transferring ownership.
Slide 08 / 12

Gamification & Karma Ledger

Incentivizing employee engagement through dynamic activity scoring and achievement badges.

🏆 Activity Scoring

Points awarded for writing articles, receiving top reactions, and answering queries.

🎖️ Tier Badges

Bronze, Silver, Gold, and Platinum badges displayed on employee profiles.

🎁 Admin Awards

System Administrators can manually grant recognition karma awards.

Global Search & Discovery Engine

Unified search bar scanning 7 distinct entity types with dynamic filters and personal search history.

  • Unified Search: Single query returns matching Users, Posts, Articles, Videos, Podcasts, Communities, and Jobs.
  • Search History: Per-user search history tracking (`FR-SD-05`) with one-click clear options.

Internal mobility job board paired with an event-driven generic notification engine.

  • Internal Job Board: HR/System Admin job posting CRUD with JobExpiryHostedService background worker.

  • Audit Trail: Immutable audit logs recording all account suspensions and admin actions.
