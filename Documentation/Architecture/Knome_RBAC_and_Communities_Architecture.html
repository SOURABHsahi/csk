1. Executive Overview & Governance Objectives

The Knome Enterprise Platform enforces strict multi-tenant Role-Based Access Control (RBAC) and granular space segmentation to ensure secure corporate communication, intellectual property protection, and authorized content governance across all departments of MPOnline Limited.

This document defines the technical policies, API authorization filters, and operational lifecycles for:

  • The 4 Core Enterprise Roles (Employee, Community Admin, HR Administrator, System Administrator).
  • The 3 Community Space Classifications (Public, Private, and Organization Default Communities).
  • The complete Community Creation & Administrative Approval Workflow.

Backend Security Enforcement

All API controllers enforce RBAC via ASP.NET Core [Authorize(Roles = "...")] filters. Claims are verified directly from cryptographic HMAC-SHA256 JWT tokens issued either by Knome API or EmployeeHub Identity Server (Dual-Issuer Trust).

3. Community Classifications: Public, Private & Default

Communities in Knome provide structured collaboration environments tailored for open discussion, specialized projects, or mandatory corporate synchronization.

public Public Community

Open corporate knowledge exchanges accessible to the entire MPOnline organization.

  • Join Process: Instant 1-click self-enrollment.
  • Approval Barrier: None required.
  • Visibility: Feeds, articles, and member rosters are 100% discoverable.
  • Use Case: Tech forums, photography clubs, innovation circles.
lock Private Community

Confidential workgroups, leadership committees, and project-specific pods.

  • Join Process: Submit Request to Join.
  • Approval Barrier: Community Admin / HR Admin must approve.
  • Visibility: Internal feeds & files hidden until membership approval.
  • Use Case: Project Phoenix, Executive Board, Legal/Finance teams.
corporate_fare Organization Default

Mandatory organization-wide spaces managed exclusively by HR Administration.

  • Join Process: Automated enrollment upon account creation.
  • Approval Barrier: N/A (Pre-assigned).
  • Visibility: Mandatory for all designated employees.
  • Use Case: All MPOnline Official, Townhalls, Compliance Updates.

4. Document Security & Sharing Governance

To maintain confidentiality and prevent data leakage across community channels:

  • Protected Sandboxed Viewer: All attached technical PDFs, briefs, and manuals open strictly within Knome's in-app DocumentViewerModal. External download links and browser save ribbons are suppressed.
  • Standardized 2-Option Share Modal: Content can only be shared to:
    1. Share to Community (Broadcast into an approved community feed).
    2. Share with Users (Targeted peer notification to specific colleagues).
  • Audit Trail Tracking: All moderator actions, community approvals, and role updates are permanently logged into dbo.AuditLogs for institutional compliance.
