12. Assumptions, Constraints, and Dependencies

12.1 Assumptions
· All employees have active AD accounts provisioned prior to Knome onboarding. · HRMS contains accurate and current employee master data (Name, Dept, Designation, Location). · An SMTP mail server is available and configured for outbound email notifications. · Microsoft Stream and OneDrive are available within the organizational M365 tenant for video integration. · A push notification service (WebSocket-capable server) will be provisioned for real-time alerts. · Organization has defined and communicated platform etiquette guidelines to employees prior to launch.
12.2 Constraints
· Platform must run on MPonline's existing on-premises or approved government cloud infrastructure. · Solution must comply with the Digital Personal Data Protection (DPDP) Act, 2023 for any personal data
processed. · All media content stored within the platform must reside on government-approved data centre
infrastructure. · Phase 1 excludes AI-driven features; all recommendation logic must be rule-based. · External social media sharing (LinkedIn, Twitter) is not permitted for government compliance reasons.
12.3 Dependencies
· HRMS API availability and stability for employee master data synchronization (INT-01). · Active Directory / SSO availability for authentication (INT-02). · Microsoft 365 tenant access for Stream and OneDrive integration (INT-04, INT-05). · Network infrastructure team to enable WebSocket ports for real-time notification service.
